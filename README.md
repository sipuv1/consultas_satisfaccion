
# ETICOS - Integración Supabase

Este proyecto incluye una integración profesional con Supabase
para almacenar respuestas de satisfacción en tiempo real.

## Incluye
✅ Conexión Supabase
✅ Tabla SQL
✅ Variables de entorno
✅ API de almacenamiento
✅ Frontend conectado
✅ Dashboard preparado
✅ Arquitectura escalable

## Pasos rápidos

1. Crear proyecto en Supabase
2. Ejecutar schema.sql
3. Configurar .env.local
4. Ejecutar frontend

## Tecnologías
- Next.js
- Supabase
- PostgreSQL
- TailwindCSS
